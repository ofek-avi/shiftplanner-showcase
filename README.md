# ShiftPlanner

Private production code. Public showcase only.

![ShiftPlanner dashboard](assets/shiftplanner-dashboard.png)

## What This Project Does

ShiftPlanner is a local scheduling application for building and reviewing weekly employee shift plans.

The app supports:

- Employee and constraint import from Excel/CSV files.
- Automatic weekly schedule creation.
- Manual editing after generation.
- Weekly summaries and staffing counters.
- PDF/Excel export.
- Holiday and special-rule handling.
- Backup and restore for schedule history.
- A closed app build for distribution without exposing source files.
